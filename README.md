# AI-Chat-Bot 🤖

An AI-powered chatbot built using **HTML, CSS, JavaScript, and the Gemini API**.  
The chatbot allows users to interact with an AI and receive real-time conversational responses through a simple and user-friendly interface.

## 🚀 Live Demo

[AI Chat Bot](https://ai-chat-bot-m-9f35.vercel.app/)

## 📌 Features

- 💬 Interactive AI chatbot
- 🤖 AI-generated responses using the Gemini API
- ⚡ Real-time conversation
- 🎨 Simple and responsive user interface
- ❌ Error handling for API requests
- 🌐 Deployed using Vercel

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Gemini API
- Vercel
